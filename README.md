# 質問トレーナー

## 【1】制作アプリのタイトル

質問トレーナー

## 【2】制作アプリの説明

企業説明会での質問の仕方を、選択肢を選んで練習できるアプリ

## 【3】工夫した点・こだわった点

- 講義のじゃんけんの仕組みをベースに、「ランダムに問題を出す→選択肢を選ぶ→コメントを表示」という形に組み替え。自分が後出しでじゃんけんするような構図と理解。
- 題材は、仕事で扱ってる講義内容をシミュレーションゲーム形式にできないかと以前考えていたことを思い出して、今回応用しました。英語版にすれば、実際に使えそうです。
- クイズ形式で〇×にしようかとも思いましたが、「質問に対する企業からの見え方」をコメントで返すようにしました。
- じゃんけんとは異なり、問題を押すごとに選択肢も切り替わり、選択肢に応じてコメントが表示されるようにしました。選択肢の文章が長いので縦並びの配置に変更。
- 同期の皆さんからデザインの重要性に触れ、以下のことに時間をかけました。
  - 説明会の場面の背景画像を置く（問題を表示する中央部分は空ける）
  - フォントを色々と試してみる（見比べているとキリがなく、コードの書き換えに地味に時間がかかる）
  - 最初の問題を出すまで選択肢を隠す
  - 選んだ選択肢に色を付ける
  - コメントを吹き出しにする

## 【4】次回トライしたいこと

- 今回は3問だけですが、問題数を大幅に増やす場合にはオブジェクトでまとめるという方法があることまで知りましたが今回はタイムオーバー。
- シミュレーションゲーム化するには、選んだ選択肢に応じて問題を切り替える、一定ラインを超えるとゲームクリア、一定のラインを下回るとゲームオーバーのような設計にしてみたい。

## 【5】備考

- 土曜の講義後〜月曜終わりくらいまで付ききりの予定があり、一度頭の中がリセットされてしまい、講義内容・課題を思い出すまでに時間がかかってしまった（一部思い出されていないものもありそう、、）。できる限り、土曜の講義直後〜日曜にかけて時間確保できるようにしたい。
- 実際に使えるものにできそうなイメージが浮かんで以降は、作業がどんどん進んでいく。とことんブラッシュアップに専念したい欲と、自分の理解が追いつく範囲に留めようモードの間の葛藤あり。
